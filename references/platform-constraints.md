## 二、为什么这个表必须存在

**反面案例**（v1.1.3 时期的错误）：
- ❌ **v1.1.3 模板**写"B 站要详细（200-500 字）"—— 错的（B 站上限 70 字）
- ❌ **v1.1.3 模板**写"昵称统一用 `二大爷和他的 AI · 铁柱`"—— 错的（B 站禁 `·`）
- ❌ **v1.1.3 默认 4 平台统一文案**—— 错的（4 平台限制完全不同）

**正面范式**（v1.6 起的 SOP）：
- ✅ **先查字数限制**（**不知道就搜**：`平台名 + 简介字数限制` / `平台名 + 昵称规则`）
- ✅ **按字数倒推内容**（**先确定字数 → 倒推内容密度 → 删废话**）
- ✅ **写完自检 2 问**：
  1. 字符数 ≤ 平台限制？
  2. 字符数 = 复制粘贴到平台后**不**被截断？
- ✅ **不能确定的字段填"待核实"** + 标"实际填入被拒就更新本表"

## 三、自检 SOP（每次写简介前必跑）

### Step 1：查本表（已经在本文件里了）
**4 平台限制速查表** 在本文档顶部。

### Step 2：用 Python 算字符数

```python
def check_platform_intro(name: str, intro: str):
    """检查昵称和简介是否符合平台限制（v1.6 速查）"""
    rules = {
        "B站":   {"nickname": 16, "intro": 70,  "no_dot": True},
        "YouTube": {"nickname": 50, "intro": 1000, "no_dot": False},
        "抖音":   {"nickname": 16, "intro": 80,  "no_dot": True},  # 部分符号禁用（待核实）
        "视频号": {"nickname": 20, "intro": 30,  "no_dot": True},  # 待核实
    }
    print(f"昵称「{name}」: {len(name)} 字符")
    if "·" in name or "、" in name:
        print(f"  ⚠️  包含禁字符 `·` 或 `、`（B 站拒）")
    print(f"简介「{intro}」: {len(intro)} 字符")
    for plat, rule in rules.items():
        if len(intro) > rule["intro"]:
            print(f"  ❌ {plat} 简介超 {rule['intro']} 字限制")
        elif rule["no_dot"] and ("·" in intro or "、" in intro):
            print(f"  ⚠️  {plat} 简介含禁字符 `·` `、`")
        else:
            print(f"  ✅ {plat} OK")

# 用法
check_platform_intro(
    "二大爷和铁柱",
    "🐶 养了只 AI 宠物叫铁柱。不太聪明但会用 AI。每周四看 TA 翻车。"
)
```

### Step 3：自检 2 问

| 问题 | 答案 |
|---|---|
| 字符数 ≤ 平台限制？ | 37 ≤ 70 ✅ |
| 字符数 = 复制粘贴后**不**被截断？ | ✅（37 字符完整保留） |
