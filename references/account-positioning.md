# 账号定位 · 完整版

> 这份文档定义账号的"为什么做"——**所有内容决策的源头**。任何"我要不要做这个选题"、"我要不要改定位"、"我要不要接广告"的问题，**先回这里看**。

## 一句话定位

**AI 工程师独立创作者：每周挖 1-2 个 GitHub 上的 AI 神器，测它到底有没有用，整合进我的工作流。**

## 三要素

### 1. 角色（我是谁）
- **AI 工程师 / Agent 操盘手**
- **独立创作者**（不是机构、不是团队、不是 MCN）
- **日常在做的事**：刷 GitHub → 选项目 → 实测 → 整合/放弃

### 2. 行动（我做什么）
**常态化动作**：
- 调研 GitHub 热门项目（Trending / 朋友推荐 / 自己挖）
- 读 README + 跑 demo
- 实测 + 记录翻车点
- 评估"能不能整合进我的工作流"
- 整合 / 写 skill 沉淀 / 放弃

**视频化动作**（你正在搭的）：
- 把上面的过程**录成视频**（顺手录，工作 0 中断）
- 周末剪 1 条 8-15 min 视频
- B 站/YouTube 同步发，抖音剪精华

### 3. 价值（对你有什么用）
- **不是云测评**（别人看 README 念稿，我**真跑**）
- **不是教程**（不讲"这个按钮怎么点"）
- **讲决策和翻车**（我为什么选这个 / 哪里踩坑了 / 怎么避）
- **看真实从业者的选型过程**（不是商业 PR）

## 人设标签

| 维度 | 内容 |
|---|---|
| **职业** | AI 工程师 / Agent 操盘手 |
| **工作日常** | 开源项目调研 × 实测 × 整合到工作流 |
| **目标用户** | 想学 AI 的创作者/工程师，愿意为方法论付费 |
| **地域** | 重庆（口音 + 直白风格是差异点，**别端着**） |
| **风格** | 工程师对工程师，**不装、不端、不娱乐化** |
| **人称** | 我 / 我们（不用"小编"、"宝子"这类词） |

## 差异化锚点（4 个）

1. **不教"怎么按按钮"，讲"怎么决策"**
   - 99% 的 AI 教学账号都在做 #1
   - 1% 讲 #2——而 #2 才是真正能复用的能力

2. **实测 + 整合工作流**
   - 大多数测评是"打开 README 念一遍"
   - 我是"真跑 + 看能不能塞进我的 pipeline"
   - 后者需要**真的在做项目的人**才能讲

3. **每期视频都有"反常识"或"踩坑"**
   - 不追"这个工具多好多好"
   - 讲"这个工具哪里让我失望 / 这个工具哪里真香"

4. **跨圈层（技术 + 创作者 + 儿童内容）**
   - 技术圈少有人把"做内容"讲得深
   - 创作者圈少有人讲"底层原理"
   - **三栖**是稀缺定位，**别丢掉任何一个**（你日常工作里 3 个都在做）

## 目标用户（3 类 + 优先级）

### P0：创作者型工程师
- **画像**：会用 GitHub，知道 LLM / Agent 是什么，正在做 side project
- **痛点**：选型困难，不知道哪个工具真有用
- **价值**：看我怎么选 = 他们的选型参考
- **付费意愿**：⭐⭐⭐（愿意为模板/课程付费）

### P1：AI 工程师/产品经理
- **画像**：在 AI 公司工作或正在转 AI
- **痛点**：技术更新太快，跟不上
- **价值**：看真实从业者的视角（**不是 PR**）
- **付费意愿**：⭐⭐⭐⭐（高客单价潜在客户）

### P2：内容创作者（宝妈/小品牌）
- **画像**：想用 AI 做内容，但不懂技术
- **痛点**：工具太多，不知道从哪开始
- **价值**：看我怎么用 = 他们的"代跑"
- **付费意愿**：⭐⭐（低客单价，但量大）

**优先服务 P0 + P1**，**P2 顺带**。

## 定位的"不要做"清单

- ❌ 不做"AI 入门科普"（赛道卷成麻花）
- ❌ 不做"AI 商业变现课"（用户已经看吐了）
- ❌ 不做"AI 工具排行榜 Top 10"（同质化严重）
- ❌ 不做"AI 编程教程"（Cursor / Claude Code 教程已经烂大街）
- ❌ 不做"AI 绘画/AI 视频"教程（虽然你会，但这不是差异化）
- ❌ 不接广告（**6 个月内**）
- ❌ 不做"团队矩阵"（1 个人，1 个号，慢节奏）

## 定位的"要做"清单

- ✅ 实测 + 翻车 + 决策
- ✅ 真实项目里的工具使用
- ✅ 跨项目的方法论沉淀
- ✅ "我做项目" 的过程实时记录
- ✅ 行业观察（少做、不定期）

## 定位会"变"吗？

**v1.0.0 锁定 12 个月**。变之前需要满足：
1. 跑满 6 个月内容（30-50 条视频）
2. 有 100+ 订阅
3. 看到清晰的"用户反馈"指向新方向

**不要因为一两条视频数据不好就改定位**——**样本不够**。

## 一句话给外人解释

> "我是 AI 工程师，每周实测一个 GitHub 上的 AI 项目，看它到底有没有用，不云测评、不教按钮，只讲我真实用下来的坑和真香。"

这句话能讲清楚，账号定位就**稳了**。
