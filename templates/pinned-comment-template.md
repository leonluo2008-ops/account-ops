# 置顶评论模板（3 条）

> **视频发布后立即发**（3 分钟内）——置顶评论 = **白拿的互动率 + 留人钩子**。

## 置顶 1（必发）：自我介绍 + 订阅引导

**目的**：让新观众 3 秒知道"你是谁、为什么关注你"。

```
👋 嗨，谢谢看到这里！

我是一个 AI 工程师，日常工作就是测各种 AI 工具、搭 Agent、用 AI 做儿童内容。

这个账号是我沉淀「选型经验」的地方——
  • 不是教程（不讲「怎么按按钮」）
  • 是真实选型日志（每个项目都实测，不云测评）
  • 重点讲决策和翻车（哪些坑要避，哪些真香）

📌 关注我，每周四更新

如果你也做 AI，评论区告诉我：
  你最近踩过最深的 AI 工具坑是什么？
  下期我可能会选一条评论里的项目做实测 🙌
```

**发完这条后**：**置顶**（B 站/YouTube 都有"置顶评论"按钮）

---

## 置顶 2：补充本期信息（FAQ）

**目的**：解决新观众的"我是谁、这账号干啥的、怎么合作"问题。

```
📂 几个你可能想问的：

Q: 你会讲什么 AI 工具？
A: 主要是开源 GitHub 项目，包括 Agent 框架、Skill 工具、MCP、视频生成、LLM 框架等。我不会讲商业 SaaS 工具（除非它真的炸裂）。

Q: 视频多久更？
A: 每周 1-2 条，B 站和 YouTube 同步发。

Q: 你的 GitHub 调研池能看吗？
A: 公开的！链接在简介里，我每周把看到的有意思的项目扔进去，包括已经测完和还没测的。

Q: 你能接广告/合作吗？
A: 现在不接。等账号稳定下来再说（毕竟这是个副业，慢慢来）。
```

**发完这条后**：**不用置顶**，**发在置顶 1 下面**（让观众按顺序看）

---

## 置顶 3：互动钩子（提升评论数）

**目的**：抛开放问题，引导观众评论（**评论数 = B 站/YouTube 算法权重的关键**）。

```
🧠 视频里我提了一个观点：

  「很多看着不起眼的项目，反而真的改变了我工作流；
    很多吹得很神的项目，测完发现是个垃圾」

你同意吗？

你有没有经历过这种「反常识时刻」——
  一个被吹爆的工具，你用了发现是垃圾；
  一个没人提的小工具，反而救了你命。

评论区讲一个你印象最深的 🙌

我会在每条评论里挑 1-2 个，下一期专门讲 🙌
```

**发完这条后**：**不用置顶**，**发在置顶 2 下面**

---

## 发布顺序

```
1. 视频发布（B 站/YouTube）
   ↓ 立即（< 3 分钟内）
2. 复制置顶 1 + 发送 + 置顶
   ↓ 立即（< 1 分钟内）
3. 复制置顶 2 + 发送
   ↓ 立即（< 1 分钟内）
4. 复制置顶 3 + 发送
   ↓ 完成
```

**总时间：5 分钟内**——**不要拖**。

## 反模式

- ❌ **24 小时后才发**（**早期评论权重大，错过没意义**）
- ❌ **只发 1 条**（**浪费流量入口**）
- ❌ **置顶 3 条**（**观众看不到后面的评论**）
- ❌ **置顶里放广告/合作**（**v1.0.0 不接**）
- ❌ **互动钩子不回复**（**置顶里说"我会看每条评论"就要真看**）

## 进阶：每条评论都回

**前 50 条评论逐条回复**——**B 站/YouTube 算法都给"创作者回复"加权**。

回复模板：

```
[对评论内容的回应，1-2 句]
[如果合适，加 1 个延伸问题引导继续聊]
```

**范例**：

> 用户评论："我也觉得 M 是垃圾，我之前用他做的 XXX 翻车了"
>
> 你的回复："哎你这个翻车具体是哪个场景？我下一期想讲 M 的 5 个坑，看看你的经历在不在里面"

**回完评论 → 引导关注 + 订阅**（**自然发生，不要硬塞**）。
