# B 站简介模板

> **每次发布前复制这份 + 改 4 个占位符**。B 站简介要**详细**（200-500 字），**留钩子**。

## 模板（复制粘贴）

```
👋 你好，我是一个 AI 工程师。

每周我会挖 1-2 个 GitHub 上有意思的 AI 项目，测它到底有没有用，然后告诉你值不值得用。

这期是 [本视频主题]——
  [一句话讲清楚这期讲什么]
  [一句话讲清楚你的结论/反常识]

📌 关注我，每周四更新（不赶进度、不追热点）

📂 这个账号的内容分 4 类：
  A 类：单项目实测（每周 1-2 条）
  B 类：横向对比（一个月 1-2 条）
  C 类：怎么把好东西整合进我的工作流（一个月 1-2 条）
  D 类：行业观察

🔗 我的 GitHub 调研池（公开 Notion）：[链接]
💬 有想让我测的项目？评论区告诉我

#AI #GitHub #开源 #实测 #选型 #Agent #[本期相关标签 1-2 个]
```

## 占位符说明

| 占位符 | 怎么填 |
|---|---|
| `[本视频主题]` | 跟视频标题对齐 |
| `[一句话讲清楚这期讲什么]` | **别用项目全名**，用人话讲 |
| `[一句话讲清楚你的结论/反常识]` | **关键**——让观众知道"看这个我能得到什么" |
| `[链接]` | Notion 调研池公开链接（账号稳定后） |
| `[本期相关标签 1-2 个]` | 按视频主题选，**别堆**（3-5 个标签最佳） |

## 范例

```
👋 你好，我是一个 AI 工程师。

每周我会挖 1-2 个 GitHub 上有意思的 AI 项目，测它到底有没有用，然后告诉你值不值得用。

这期是我自己开发的园丁 skill 完整实测——
  它能从你和 AI 的真实工作对话里，自动挖出值得沉淀的 skill 机会。
  我实测了 3 个项目，结论是：能用，但没你想的那么神。

📌 关注我，每周四更新（不赶进度、不追热点）

📂 这个账号的内容分 4 类：
  A 类：单项目实测（每周 1-2 条）
  B 类：横向对比（一个月 1-2 条）
  C 类：怎么把好东西整合进我的工作流（一个月 1-2 条）
  D 类：行业观察

🔗 我的 GitHub 调研池（公开 Notion）：https://app.notion.com/p/37aa3f9269aa8082a264ce2897ec8229
💬 有想让我测的项目？评论区告诉我

#AI #GitHub #开源 #实测 #选型 #Agent #skill
```

## 关键原则

- ✅ **详细**（200-500 字）
- ✅ **含定位 + 这期内容 + 4 类预告 + 标签 + Notion 链接**
- ✅ **留钩子**（"调研池公开" + "评论区告诉我"）
- ❌ **不要堆关键词**（B 站算法不像 SEO，**会降权**）
- ❌ **不要写"商务合作请私信"**（**v1.0.0 不接广告**）
