# 视频大纲模板

> **写脚本前先写大纲**——避免"边写边跑题"。

## 视频元数据

```
视频标题：[草稿，3 个候选]
视频类型：A / B / C / D
目标时长：X 分钟
目标发布日期：YYYY-MM-DD
对应选题：[选题库那条的标题]
```

## 5 段式结构（按视频类型调整时长）

| 段 | 时长 | 核心任务 | 必含 |
|---|---|---|---|
| **1. 钩子** | 0-15s | 让观众看下去 | 一句反常识/挑战/抛问题 |
| **2. 背景** | 15s-1min | 观众知道在讲啥 | 项目是什么 / 为啥看它 |
| **3. 主体** | 1min - X | 核心内容 | 实测 / 横向 / 整合 / 观察 |
| **4. 翻车** | X - Y | 差异化 | 必须有 |
| **5. 结论 + CTA** | Y - end | 转化 | 推荐 + 关注 |

**X / Y 按类型调整**：

| 类型 | 主体 | 翻车 | 合计 |
|---|---|---|---|
| A（10-15 min） | 5-8 min | 2-3 min | 8-12 min + 钩子 + 结论 |
| B（15-20 min） | 8-10 min | 3-5 min | 12-16 min + 钩子 + 结论 |
| C（10-15 min） | 5-8 min | 2-3 min | 8-12 min + 钩子 + 结论 |
| D（8-10 min） | 5-7 min | 2-3 min | 7-10 min + 钩子 + 结论 |

## 关键数据/证据清单

**视频里要展示的**：

- [ ] 数据 1（如：实测的响应时间）
- [ ] 数据 2（如：跑出来的截图）
- [ ] 数据 3（如：踩坑的错误日志）
- [ ] 链接 1（如：GitHub repo）
- [ ] 链接 2（如：Notion 调研池）

**没证据 = 不做**——**云测评的反义词**。

**最终选 1 个**（如果 0 个 = 改选题）。
