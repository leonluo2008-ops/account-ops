# 视频脚本模板

> **用之前先看 `references/workflow-sop.md#2-脚本撰写`**——这模板只是"骨架"，完整 SOP 在那边。

## 视频元数据（顶部必填）

```
视频标题：[一句话标题，含钩子]
视频类型：A 单项目实测 / B 横向对比 / C 整合到工作流 / D 行业观察
目标时长：X 分钟
对应选题：[选题库那条的标题]
出镜方式：屏幕录 + 真人配音 / 半出镜 / 全出镜
```

---

## 镜头 1：钩子（0:00 - 0:15）

**画面**：[简述画面]

**配音稿**：
> "[一句话钩子/挑战常识/抛问题]
>
> [第二句铺垫/钩子加强]"

**节奏要求**：
- 前 3 秒必须有钩子（**不然后 80% 观众划走**）
- 钩子用"反常识"或"踩坑"，**不要用"震惊！"这种标题党**

---

## 镜头 2：背景（0:15 - 1:00）

**画面**：[简述画面 + 字幕条提示]

**配音稿**：
> "[这个项目/选题是什么]
>
> [我为什么看它 / 它哪里吸引我]
>
> [它号称能解决什么问题]"

**节奏要求**：
- 3 句话讲清楚，**别长**
- 不要"在开始之前我们先..."这种过渡词

---

## 镜头 3：实测过程（1:00 - X 分钟）

**画面**：[录屏 + 关键节点 + 字幕标注]

**配音稿**：
> "[步骤 1：怎么测的 + 跑出来什么]
>
> [步骤 2：...]
>
> [步骤 N：...]"

**节奏要求**：
- **核心价值**——观众看这里
- 关键判断加重语气
- 跑出来的数据/截图/异常**要展示**（不要光说）

---

## 镜头 4：翻车 / 反常识（X - Y 分钟）

**画面**：[录屏 + 字幕红字标注]

**配音稿**：
> "[这里我踩了 / 哪里出乎意料]
>
> [具体说]"

**节奏要求**：
- **必须有这一段**——没有 = 云测评
- 语气转严肃，"反常识"加重
- 配字幕特效

---

## 镜头 5：结论 + CTA（Y - end）

**画面**：[真人露脸 / 屏幕收尾]

**配音稿**：
> "[结论：推荐 / 不推荐 / 部分场景推荐]
>
> [适用人群：XXX 类用户]
>
> [CTA：点订阅 / 关注 / 评论]"

**节奏要求**：
- 结尾不要"以上就是本期视频的全部内容"这种废话
- **直接 CTA**——"我是 [你的名字]，我们下期见"

---

## 关键提示（每次写完检查）

- [ ] 总时长 8-15 min（**D 类 8-10 min，A/B/C 类 10-15 min**）
- [ ] 中文单行不超过 12 字（**口语节奏**）
- [ ] 关键判断加重语气
- [ ] 长句拆短句
- [ ] 结尾有 CTA
- [ ] 翻车点存在
