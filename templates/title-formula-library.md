# 标题公式库

> **标题 = 30% 内容 + 70% 包装**。一份完整的公式库，**让你以后随手写标题**。

## 核心原则

1. **25 字以内**（B 站）/ **60 字符以内**（YouTube）
2. **含钩子**（数字 / 反常识 / 挑战常识 / 悬念）
3. **跟你人设匹配**（**不装、不端、不娱乐化**）
4. **不用"震惊"、不用"!"、不用"速看"**（**反你账号调性**）

## 5 大公式

### 公式 1：实测型（**A 类专用**）

**结构**：`[钩子动词] + [项目] + [结论/反常识]`

**范例**：
- "我试了 Meta skill：号称能自动生成 skill，实际用下来..."
- "实测 Claude Code 一周：3 个真相 + 2 个坑"
- "我测了 5 个 AI Agent framework：结论是..."

**关键点**：
- "我试了"、"我测了" → **第一人称 + 真实感**
- 结论不剧透 → **留悬念**

### 公式 2：挑战常识型（**A/B/D 类**）

**结构**：`[反常识观点] + [项目/品类]`

**范例**：
- "GitHub 上最火的 AI 工具，实测后我劝你别用"
- "号称比 LangChain 强 10 倍，我测完沉默了"
- "5 个被吹爆的 AI 神器，3 个是垃圾"

**关键点**：
- **敢说"垃圾"**——**人设调性**
- "我劝你别用"、"沉默了" → **情绪钩子**
- **不要写"震惊"、不要写"!"**——**跟你人设冲突**

### 公式 3：数字型（**A/B/D 类**）

**结构**：`[数字] + [项目/品类] + [钩子]`

**范例**：
- "我实测了 7 个 MCP 工具，最该用的是这个"
- "AI 工具选型清单：5 个真香 + 3 个坑"
- "我看了 50 个 AI 工具，得出 5 个结论"

**关键点**：
- **数字让标题"看起来"实在**
- **"5 个真香 + 3 个坑"** 这种对比有钩子

### 公式 4：整合型（**C 类专用**）

**结构**：`[动作] + [项目] + [结果/代价]`

**范例**：
- "把 [工具] 整合进我的 Hermes pipeline，我踩了 3 个坑"
- "我花了 2 周把 [工具] 塞进工作流，结论是..."
- "[工具] 实战集成：30 分钟教你塞进我的多 agent 系统"

**关键点**：
- **"我花了 X 时间"** → 真实成本
- **"3 个坑"** → 翻车点预告
- **"塞进"** → 工程师调性

### 公式 5：观点型（**D 类专用**）

**结构**：`[观点] + [支撑]`

**范例**：
- "AI Agent 赛道的 3 个反常识"
- "为什么我不看好 [品类/项目]"
- "我看了 GitHub Trending 本周 Top 10，最该看的是..."

**关键点**：
- **观点要敢站队**
- "3 个反常识" → 数字 + 挑战

## 标题调性自检（写完检查）

- [ ] **25 字以内**（中文）/ **60 字符以内**（英文）
- [ ] **含钩子**（数字 / 反常识 / 悬念）
- [ ] **第一人称**（"我试了"、"我测了"）—— *选填，但能加分*
- [ ] **没有"震惊"、没有"!"、没有"速看"**
- [ ] **没有 emoji**（emoji 在标题里，**跟你工程师调性冲突**）
- [ ] **跟你人设匹配**——**不装、不端、不娱乐化**
- [ ] **3 秒读不懂 = 改**

## 反模式

- ❌ **"震惊！这个 AI 工具太强了！"** —— 标题党，跟你人设不符
- ❌ **"AI 工程师必看！"** —— 自嗨，**观众不是 AI 工程师**
- ❌ **"【建议收藏】..."** —— 信息密度低
- ❌ **"[项目名] 教程"** —— 跟 99% 教程号撞型
- ❌ **emoji 大杂烩** —— **不专业**
- ❌ **30+ 字长标题** —— **小图看不清**

## 标题 3 次迭代 SOP

**写完第 1 版**：
- 套公式 → 写 5 个候选标题

**选 1 个 + 优化**：
- 套调性自检 → 改到全过

**最终测试**：
- **5 秒测试**：手机小图能不能看清？
- **不懂测试**：发给 1 个朋友，问"你看这标题想点开吗"？

| "震惊！速看！必看！" | "我试了 XXX：3 个真相 + 2 个坑" | 情绪 → 标题党 |
