# YouTube 简介模板

> **每次发布前复制这份 + 改占位符**。YouTube 简介要**简洁**（100-200 词），**英文**，**hashtag 格式**。

## 模板（复制粘贴）

```
Hi, I'm an AI engineer.

Every week, I dig up 1-2 interesting AI projects on GitHub, test if they actually work, and tell you whether they're worth your time.

This is a NO-FLUFF, REAL-TESTING channel. I don't do cloud reviews (just reading the README). I actually run the tools and tell you if they break.

📌 New video every Thursday

📂 Content categories:
  Type A: Single project deep test (1-2/week)
  Type B: Side-by-side comparison (1-2/month)
  Type C: How I integrate the good ones into my workflow (1-2/month)
  Type D: Industry observation

🔗 My GitHub research pool (public Notion): [link]
💬 Got a project you want me to test? Drop it in the comments.

#AI #GitHub #OpenSource #TestedNotReviewed #Agent #LLM #[本视频相关 1-2 个]
```

## 占位符说明

| 占位符 | 怎么填 |
|---|---|
| `[link]` | Notion 调研池公开链接 |
| `[本视频相关 1-2 个]` | 视频主题相关的英文 hashtag |

## 范例

```
Hi, I'm an AI engineer.

Every week, I dig up 1-2 interesting AI projects on GitHub, test if they actually work, and tell you whether they're worth your time.

This is a NO-FLUFF, REAL-TESTING channel. I don't do cloud reviews (just reading the README). I actually run the tools and tell you if they break.

In this video: my own open-source project gardener-skill — it auto-mines skill opportunities from your real AI work conversations. I tested it on 3 projects. Verdict: it works, but not as magical as the README suggests.

📌 New video every Thursday

📂 Content categories:
  Type A: Single project deep test (1-2/week)
  Type B: Side-by-side comparison (1-2/month)
  Type C: How I integrate the good ones into my workflow (1-2/month)
  Type D: Industry observation

🔗 My GitHub research pool (public Notion): https://app.notion.com/p/37aa3f9269aa8082a264ce2897ec8229
💬 Got a project you want me to test? Drop it in the comments.

#AI #GitHub #OpenSource #TestedNotReviewed #Agent #LLM #ClaudeCode
```

## 关键原则

- ✅ **简洁**（100-200 词）
- ✅ **英文**
- ✅ **hashtag 格式**（YouTube 算法偏爱）
- ✅ **直译 + 重新写**（**不是中文版的机翻**）
- ❌ **不要堆链接**（YouTube 会降权）
- ❌ **不要写"商务合作"**（**v1.0.0 不接广告**）
