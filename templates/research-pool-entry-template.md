# 调研池条目模板

> **30 秒填一个项目**——用模板复制粘贴，只改 4 个核心字段。

## 必填（4 个）

| 字段 | 填什么 | 范例 |
|---|---|---|
| **项目名** | GitHub repo 全名（`owner/repo`） | `leonluo2008-ops/gardener-skill` |
| **GitHub URL** | 复制 GitHub 仓库 URL | `https://github.com/leonluo2008-ops/gardener-skill` |
| **来源** | 从下拉菜单选 1 个 | `GitHub Trending` / `朋友推荐` / `自己挖到` |
| **一句话理由** | 30 秒写"为什么想看" | "号称能从 AI 对话里挖出 skill 机会，听起来很玄" |

## 推荐填（3 个，按需）

| 字段 | 什么时候填 |
|---|---|
| **分类** | 多选，从 9 个标签里选（AI Agent / Skill 框架 / MCP 工具 / LLM 框架 / 视频生成 / 图像生成 / TTS/音频 / 开发工具 / 其他） |
| **Stars** | 看了 GitHub 页面顺手填（**不是必须**） |
| **加进池子时间** | 不填（**Notion 自动记录**） |

## 选填（看完再填）

| 字段 | 什么时候填 |
|---|---|
| **调研状态** | 默认 "🔍 待调研"；读完 README 改 "📖 读 README 中"；实测完改 "✅ 可整合" 或 "❌ 放弃" |

## 填好的范例

```
项目名：leonluo2008-ops/gardener-skill
GitHub URL：https://github.com/leonluo2008-ops/gardener-skill
来源：自己挖到
分类：Skill 框架, AI Agent
Stars：12
调研状态：✅ 测完，可整合
一句话理由：号称能从你和 AI 的真实工作对话里挖出 skill 机会，我实测了 3 个项目，确实能用，但误报率还比较高
```

## 反模式

- ❌ **30 分钟填一个项目**（**30 秒就行**，其他字段以后补）
- ❌ **当天就决定做不做**（**让理由自己发酵 3-7 天**）
- ❌ **不写"一句话理由"**（**未来你看不懂当时为啥选它**）
- ❌ **状态永远是"🔍 待调研"**（**至少 7 天推进一次状态**）

## 流转规则

```
🔍 待调研（默认）
  ↓ 看完 README
📖 读 README 中
  ↓ 开始 clone + 跑 demo
🧪 实测中
  ↓ 跑完 + 决定
✅ 测完，可整合 ←── 准备进选题库
  或
❌ 不适合/放弃 ←── 写放弃理由
```

**"✅ 测完，可整合"** 的项目 → **复制到「🎬 视频选题库」**作为新选题。

## 一句话理由的写法（**关键**）

**好**：
- "号称能从 AI 对话里挖出 skill 机会，听起来很玄"
- "最近 Trending 第 1，想看看到底是神还是鬼"
- "朋友老王推荐，他说他用着很爽"
- "看到 awesome-xxx 列表里被推荐了"

**不好**：
- "看起来不错"（**没具体**）
- "想看看"（**没理由**）
- "AI 相关的"（**废话**）

**好理由的特征**：
- **有具体出处**（"Trending 第 1"、"朋友老王说"）
- **有具体判断**（"听起来很玄"、"被吹得很神"）
- **有具体期待**（"想看看到底能不能 X"）

**30 秒能写出来 = 写好了**。
